Casos reais

Leitura de hodômetro via WhatsApp

Os caminhoneiros precisavam enviar a foto do hodômetro todos os dias, às vezes duas vezes ao dia, e um funcionário passava o dia anotando os dados. Criei um chatbot no WhatsApp que recebe a foto, lê o hodômetro com IA e salva tudo em um banco de dados que estruturei.

  1. Primeiro contato: cadastro apenas com o CPF, para vincular o número ao motorista.
  2. Contatos seguintes: basta confirmar a identidade.
  3. O chatbot pede a placa do caminhão.
  4. O motorista envia a foto do hodômetro.
  5. A API da OpenAI extrai a leitura da imagem.
  6. Os dados são salvos no banco de dados.

Resultado Substituiu a anotação manual, que ocupava um funcionário durante o dia todo.

  • WhatsApp
  • OpenAI API
  • PostgreSQL
